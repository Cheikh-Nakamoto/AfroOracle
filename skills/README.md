# Skills (vendored)

Curated subset of [mattpocock/skills](https://github.com/mattpocock/skills) (MIT), vendored as methodology reference for the coding agents that build this prototype. Each skill is a `SKILL.md` describing a repeatable engineering move.

| Skill | What it is for |
| --- | --- |
| [to-spec](to-spec/SKILL.md) | Synthesize a spec from what is already known (no interview) |
| [implement](implement/SKILL.md) | Code a piece of work from a spec or ticket |
| [tdd](tdd/SKILL.md) | Red-green loop, test at public seams |
| [code-review](code-review/SKILL.md) | Review completed work |
| [prototype](prototype/SKILL.md) | Throwaway code to answer one design question |
| [research](research/SKILL.md) | Read docs/APIs to surface a fact a decision waits on |
| [handoff](handoff/SKILL.md) | Compact a session into a handoff doc for the next agent |
| [writing-for-agents](writing-for-agents/SKILL.md) | How to write docs agents consume (context pointers, single source of truth) |
| [chief-of-staff](chief-of-staff/SKILL.md) | Coordinate subagents, protect context, keep a wiki |

The pipeline that consumes these is defined in [`../PIPELINE.md`](../PIPELINE.md). License: [`LICENSE`](LICENSE).
